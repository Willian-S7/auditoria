Auditoria API:

API REST desenvolvida com Java e Spring Boot para gerenciamento de produtos, categorias e usuários, com o objetivo de implementar um módulo de auditoria capaz de registrar automaticamente alterações realizadas no banco de dados.

O projeto simula um sistema corporativo no qual é necessário identificar quais informações foram modificadas, quando ocorreram as alterações e quem foi o responsável.

Tecnologias utilizadas

Java 25
Spring Boot 4.1.2
Maven
Spring Data JPA / Hibernate
PostgreSQL
Flyway
Docker e Docker Compose
Jakarta Validation
JUnit 5 e Mockito

Objetivo do projeto:
Desenvolver uma solução de auditoria para uma aplicação corporativa, aplicando boas práticas de arquitetura backend, persistência relacional, integridade de dados, versionamento de banco e testes automatizados.

Status:
Projeto em desenvolvimento. CRUDs implementados; módulo de auditoria automática, filtros e testes ainda pendentes.
